# Licencia de los datos

Los snapshots, tablas y demas datos derivados incluidos bajo `data/snapshots/` se
publican bajo la licencia del dataset de origen:

**Community Data License Agreement - Sharing - Version 1.0 (CDLA-Sharing-1.0)**

- Texto oficial: https://cdla.dev/sharing-1-0/
- Dataset de origen: https://www.kaggle.com/datasets/ealtman2019/ibm-transactions-for-anti-money-laundering-aml
- Publicador original en Kaggle: Erik Altman
- Organizacion asociada al generador: IBM

La CDLA-Sharing-1.0 permite usar y publicar los datos con estas condiciones, entre
otras:

1. los datos recibidos y los datos mejorados deben publicarse bajo la misma licencia;
2. debe conservarse el credito o atribucion a los proveedores originales;
3. los archivos que contengan datos modificados deben llevar avisos destacados de que
   fueron modificados;
4. no pueden imponerse restricciones adicionales sobre el uso o publicacion de los
   datos.

El texto oficial e inalterado enlazado arriba es el que rige. Este resumen es solamente
informativo y no sustituye la licencia.

## Alcance

Esta licencia se aplica a los datos derivados y snapshots, no concede derechos sobre
marcas de IBM o Kaggle y no implica que dichas entidades respalden este proyecto.

La licencia de datos tampoco debe interpretarse como una licencia para el codigo,
scripts, workflows o documentacion del repositorio. Actualmente el repositorio no
declara una licencia separada para esos elementos.
